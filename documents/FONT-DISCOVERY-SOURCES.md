# Studio font-discovery sources

Verified 3 November 2026. Every live preview in this collection is licensed under SIL Open Font License 1.1. The actual licence text was checked for each entry, and all 12 pinned webfonts loaded in browser verification. No font binaries are stored in this repository. Existing licensed portfolio fonts are unchanged.

Fontsource’s public API supplied nine metadata records; designer credits came from publisher metadata. Three independent fonts use official Velvetyne repositories. Metadata is cached as source data; only the selected font file is requested by the browser. No scraper, credentials or paid service is used.

Exact metadata sources, pinned font URLs, weights and verification dates are recorded in `src/lib/studio/font-catalogue.js`. Fontsource API documentation: https://fontsource.org/docs/api/font-id.

The 13 displayed lines are original text written for this feature. The visible origin label was removed at Jenna’s request; none is assigned a historical author. Credits and licence sources remain recorded here and in the catalogue. Descriptions of font character are editorial observations, separate from the verified designer/licence metadata.

To extend the catalogue, verify the publisher, font credit, actual licence and web embedding permission first. Pin an approved webfont version and test its preview. For any commercial or unverified font, omit the font-file URL and provide an official external specimen link; do not download or embed it.

The optional Font details control now fetches current public metadata from Fontsource through a protected server action. Only curated Fontsource IDs are accepted and responses are validated/cached for 24 hours. Independent foundry entries continue to use publisher links. This replaces the Color API as the separate external-data API demonstration; it does not change font licences or the daily-selection rules.
